# Python ToDoList

A simple task management application built with Python and SQLite.

## About the Project

Python ToDoList is a personal software development project
that allows users to manage their tasks through a
command-line interface.

The application uses SQLite to store tasks persistently,
so they remain available after the program is closed.

This project will evolve over time as I continue to develop
and improve its functionality.

## Current Features

- Create tasks
- View saved tasks
- Edit task details
- Change task status
- Update task deadlines
- Add, extend, and remove task notes
- Delete tasks
- Validate date input
- Store tasks in an SQLite database

## Getting Started

### Prerequisites

- Python 3
- Git (optional, for cloning the repository)

### Installation

Clone the repository:

    git clone <repository-url>

Navigate to the project directory:

    cd Python-ToDoList

Run the application:

    python main.py

The application uses SQLite to store tasks in a local
database file.
